# Local Minecraft test procedure

Quick check: run `gradle runClientGameTest` in `fabric-mod/`. It starts a real Minecraft client with a temporary world in `build/run/clientGameTest`, opens a game window for about a minute, fails on mixin errors or broken checks, and saves screenshots in `build/run/clientGameTest/screenshots`. Review those by eye. It uses a development profile, not a real account, and does not cover multiplayer or manual mouse and keyboard use, so the steps below remain useful. The steps below use the same kind of Fabric profile that NicoClient's PLAY button sets up in the official launcher.

1. Build using Java 21 or later and Gradle 9.8.2: run `gradle build` in `fabric-mod/`. Use `build/libs/nicoclient-fabric-0.1.0.jar`, the remapped output, not a development jar. No Gradle wrapper is currently included.
2. Set up a legitimate Minecraft Java 1.21.11 installation using Fabric Loader 0.20.1 or later and a matching Fabric API for 1.21.11 (the build uses 0.141.6+1.21.11). Use a separate test profile and back up any existing test data. Configure that profile's **game directory** as `%APPDATA%\NicoClient` if testing the launcher's isolated folder; verify the profile before launching. Use Java 21 or newer.
3. Start NicoClient once to create `%APPDATA%\NicoClient\mods`, or create that directory yourself. Put the Fabric API jar and the built NicoClient jar in it, avoiding duplicate versions or overwriting existing files. The launcher can open this folder in Settings and PLAY installs these mods automatically. Merely copying a jar there does not launch or test it.
4. Start the separate Fabric profile with that game directory. Check its log for NicoClient, Fabric API, and mixin errors. In a disposable single-player world, press Right Shift. Check search, category cycling, pagination, favorites, module toggles, the settings screen, and saving after closing and restarting Minecraft. Check the FPS and Keystrokes HUDs and drag them in the HUD editor. Test Zoom by enabling it and holding C; change its factor. Set Fullbright to each ambient level, compare a dark area with the module on and off, and check that disabling restores normal lighting. Test Low Fire while actually burning and verify some fire remains visible; compare ordinary particles with Reduced Particles on and off.
5. Enable Trajectories. Test a drawn bow at multiple draw strengths, snowballs, all egg variants, ender pearls and splash potions against open terrain, a wall, and a stationary entity. Compare actual projectiles against the prediction; test the impact-marker setting and verify the path disappears when disabled or when no supported item is held. Test camera modes and any renderer mods separately. Record versions, steps, logs, and discrepancies before calling anything verified.

The predicted line is approximate: it assumes fixed drag and gravity, uses the current client-side aim and velocity and known block/entity positions, and limits the simulation to 160 ticks. It does not model random projectile spread, fluid drag, moving targets, server latency, unloaded chunks, modded physics or every enchantment. The marker shows only a predicted collision, not a guaranteed impact. Real gameplay results can differ.
